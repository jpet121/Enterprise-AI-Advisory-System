# Portfolio publication package | not an executable release

**Contents:** The parent directory is the root of a GitHub **documentation/evidence** repository for an actively used daily Oracle HCM/ERP solution advisor, with exact original instruction/test/operations sources, a synthetic Oracle CPUS case, frozen first answer, ten-role same-context review, improved recommendation, designed acceptance suite, supplemental scenarios, reference citations and verified local file manifest.

**This is not:** a Python wheel, a CLI, a fine-tuned LLM, an Oracle Fusion integration, an installed AI agent, a tenant-tested application, a published Oracle product, an audited payroll/finance system, a completed independent SME review or approved customer deployment.

**Install to a staged ChatGPT Project:** follow [README](../README.md) and exact [`03_DEPLOYMENT_AND_MAINTENANCE.md`](../docs/03_DEPLOYMENT_AND_MAINTENANCE.md). Use the short Project Instructions field as directed, upload the four Markdown knowledge files and run fresh-chat behavioral acceptance tests. Do not assume any available Oracle subscription/licensing.

**Integrity:** validate against [`SHA256_MANIFEST.json`](../SHA256_MANIFEST.json). No binary customer-production release archive is provided here. Status is separated in [`RELEASE_STATUS.md`](../RELEASE_STATUS.md); customer use is **HOLD / NOT APPROVED**.

The owner requires real Oracle resource citations for Oracle-specific recommendations and personally conducts red-team challenge. The stricter expectation is documented in [daily use and evidence standard](../docs/DAILY_USE_AND_EVIDENCE_STANDARD.md) without altering archived v1.0 instructions.

**Change management:** this is a snapshot of Advisor v1.0. Reviewed edits are recommendations in separate files. Do not merge them into governing v1.0 sources without the owner's decision and validation.
